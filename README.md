# BloxCraft
### OpenGL game made without game engine, inspired by Minecraft
Developed using: C++, Visual Studio, OpenGL  

  
## Version 0.0.26.7.10
This is the first official version of this project that includes everything that's been made so far.

###  Additions:
- Basic rendering of the objects with textures
- Basic movement and aiming mechanics
- Basic lighting with one spawned spot light
- More light types: spot light, point light
